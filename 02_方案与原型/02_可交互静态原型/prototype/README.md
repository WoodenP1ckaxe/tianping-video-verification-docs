# 天平校验视频分析系统 · 前端快速原型

**用途**：给客户逐页确认《天平校验视频分析系统 需求规格说明书 V0.9》的功能是否符合预期。

**性质**：纯静态前端原型。无后端、无数据库、无真实鉴权；所有页面数据为内置模拟数据，**刷新浏览器即恢复初始状态**。图片、视频、识别截图一律使用占位图形，不加载任何真实素材。

---

## 1. 快速开始

### 1.1 本地预览

```bash
cd prototype
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

任意静态服务器均可，例如 `php -S 0.0.0.0:8080`、`npx serve -l 8080`（需有外网）。

> 直接用浏览器双击 `index.html`（file:// 协议）同样可以打开：全站没有使用 ES Module、fetch 与外部资源，不依赖 HTTP 协议。

### 1.2 部署到 Linux 服务器（公网查看）

整目录是**零依赖静态站点**，复制到 Web 根目录即可：

```bash
# 上传（示例）
scp -r prototype user@server:/var/www/tianping-prototype

# 权限
ssh user@server
sudo chown -R www-data:www-data /var/www/tianping-prototype
```

**nginx 配置片段**（`/etc/nginx/conf.d/tianping.conf`）：

```nginx
server {
    listen 80;
    server_name tianping.example.com;

    root /var/www/tianping-prototype;
    index index.html;

    # 全部为静态文件；hash 路由不需要 try_files 重写
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 原型文件体积很小，可开启缓存
    location ~* \.(css|js|svg|png|jpg)$ {
        expires 7d;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 1.3 可选：给公网地址加一层口令保护

原型没有登录鉴权（页面上的登录页只是界面演示），如需限制访问范围，用 Basic Auth：

```bash
sudo apt-get install -y apache2-utils
sudo htpasswd -c /etc/nginx/.htpasswd demo      # 按提示设置口令
```

```nginx
    location / {
        auth_basic           "天平校验原型演示";
        auth_basic_user_file /etc/nginx/.htpasswd;
        try_files $uri $uri/ /index.html;
    }
```

### 1.4 子路径部署

站内所有资源与路由均为相对路径，可直接部署在子路径（如 `https://example.com/tianping/`），无需修改任何代码。

```

├─ index.html                 应用入口（单页 + hash 路由）
├─ README.md                  本文件
└─ assets/
   ├─ css/app.css             全站样式（含 A4 打印样式）
   └─ js/
      ├─ data.js              模拟数据（账号/天平/砝码盒/记录/读数/任务/审计/模板/存储）

      ├─ store.js             前端内存状态与业务动作（登录、提交、复核、退回、作废、队列推进…）
      ├─ components.js        通用组件（布局、表格、弹窗、提示、占位播放器、识别截图占位…）
      ├─ views-common.js      登录、演示导览、记录查询、记录详情、天平历史
      ├─ views-inspector.js   工作台、视频上传、我的上传与任务、记录核对与提交
      ├─ views-verifier.js    待复核、复核详情、主数据管理、模板配置、导出与打印
      ├─ views-admin.js       账号与角色、审计日志、存储与运行状态

      └─ router.js            hash 路由、权限守卫、事件代理与全局动作
```

## 6. 原型已模拟的关键行为

| 行为 | 说明 |
| --- | --- |
| 首次登录强制改密 | 用 `U001` 登录即触发；改密后进入工作台 |
| 账号停用 | 用 `U004` 登录提示"账号已停用，无法登录"，历史记录不受影响 |
| 口令错误锁定 | 手工登录连续输错 5 次，提示锁定 10 分钟 |
| 会话超时 | 30 分钟无操作自动登出（顶栏账号菜单可查看提示） |
| 元数据缺失 | 上传时始终演示"未读取到拍摄时间"，必须人工确认拍摄开始时间 |
| 当日重复上传 | 选择当天已有记录的天平，弹出"该天平当日已有记录"提示并可继续 |
| 队列推进 | 「我的上传与任务」页点「推进分析队列」，按 FIFO 依次完成分析并生成待提交记录 |
| 低置信修正 | 核对页低置信字段高亮，修正需填写理由，修改前后值写入痕迹与审计日志 |
| 判定实时重算 | 修正示值后，限度/偏差/是否在限内/整体结论立即按 `|I−L| ≤ 0.05%×L` 重算 |
| 提交校验 | 低置信未核对、必填项为空时阻止提交并列出原因 |
| 复核与锁定 | 复核确认（电子签名）后所有字段只读；退回可填理由并回到"待提交" |
| 作废 | 管理员作废需填理由；作废记录只读、不参与统计，单条导出带"已作废"水印 |
| 容量告警 | 「存储与运行状态」页拖动容量滑块到 90% 以上触发告警条与审计记录 |
| 审计留痕 | 上述每个动作都会实时追加到审计日志，并标注「本次会话」 |
| 需求标注开关 | 顶栏「需求标注」开关可隐藏页面上的 FR 编号，隐藏后即为正式系统观感 |

## 7. 注意事项

- 本原型**不包含**任何真实业务逻辑、数据库、文件存储与识别能力；性能类（PR）、实现约束类（CR）与质量类（QR）需求不通过界面演示，验收时以《测试与验收报告》为准（说明见原型内「演示导览」页）。
- 页面内所有天平、人员、记录、读数均为说明书与客户 Excel 中的示例数据，不含任何客户真实生产数据。
- 交付内容**未修改**仓库内原有的《需求规格说明书》与「客户原需求」目录。
