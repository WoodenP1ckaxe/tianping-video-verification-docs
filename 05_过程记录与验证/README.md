# 过程记录与验证

本目录按时间和技术主题保存可追溯的过程证据。报告均为当时状态，后续结论可能
发生覆盖；引用时务必保留目录名或文件名中的日期。

## 目录说明

- `01_阶段审查与测试脚本/`：2026-10/11 的审查报告、审计脚本、接触表和构建日志。
- `02_完整回归_20261121/`：队列压力、安全 CSV 截断和登录安全检查及完整报告。
- `03_回归修复_20261122/`：PDF 相关修复说明、检查脚本和修复后样例。
- `04_首次运行修复_20261123/`：首次运行问题修复记录。
- `05_远程4核4G验证_20261122/`：远程容器环境的并发、上传续传、ASR、导出测试。
- `06_导出审计_20261108/`：单条、批量、周统计、空白表和标准流程导出样例。
- `07_示值识别证据/`：三组样例的九次示值接触帧及总览图。
- `08_成像与合成样例/`：合成设备卡、人员卡和样例清单元数据。
- `09_ASR音频审计/`：语音识别音频长度、序列和置信度审计。

旧版本 CI 构建产物未收录；它们属于可重新生成的发布构建，不是文档证据。
