## 目录结构

- `00_导航与说明/`：编写入口、来源、筛选口径与文件校验清单。
- `01_需求与客户资料/`：需求规格、客户补充材料、测试视频及项目提案。
- `02_方案与原型/`：早期静态原型和完整页面截图。
- `03_系统技术文档/`：架构、部署、用户、运维、ASR、安全及验收文档。
- `04_源码与测试/`：当前工程源码、测试、脚本和部署配置快照。
- `05_过程记录与验证/`：回归、修复、远程资源验证、导出与识别证据。
- `06_交付与发布说明/`：最新 v1.0.9 的说明、快速开始和校验和。
- `07_历史与阶段报告/`：带明确日期的阶段性核查与测试报告。

## 使用约定

1. 引用结论时同时标明报告日期；过程报告反映当时状态，不代表最新实现。
2. 需求、架构、用户手册和测试报告发生冲突时，以较新的系统文档与当前源码为准，
   并回到对应测试证据核实。
3. 本仓库不保存生产口令、私钥、数据库、客户运行数据、安装包或 ASR 大模型。
4. 新增文件前先阅读 [来源与筛选说明](00_导航与说明/来源与筛选说明.md) 和
   [文件清单](00_导航与说明/文件清单_SHA256.csv)。
