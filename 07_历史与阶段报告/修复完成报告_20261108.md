本轮已修复测试报告中除中文 ASR 外可闭环的代码与交付问题。

最终验证：

- 行覆盖率 81.82%，分支覆盖率 63.93%，函数覆盖率 86.83%；
- 三段真实视频双轮结论全部正确且可重复；
- 三份回归清单与当前稳定段识别结果逐字段、偏移、稳定状态和量程一致；
- 桌面、移动端、平板端、三角色浏览器主流程通过；
- 合成真实视频完成浏览器上传、分析、九项读数、识别帧和记录生成；
- 单日表、周统计和空白表按客户 Excel 的逐项行/日期列结构重构；
- 1 万条记录筛选 P95 从约 612 ms 降至约 21 ms；
- 旧数据库在线备份升级验证通过：完整性正常，11/11 条历史记录补齐判定快照。

## 2. 已修复

### 账号与安全

- 连续 5 次口令错误锁定账号 10 分钟，并写“账号锁定”审计；
- 未知账号按来源 IP 在 5 分钟窗口限流；
- 验证码接口对存在/不存在账号统一返回 410，消除账号枚举；
- 用户改密后撤销同账号其他会话，当前会话保留；
- 登录 JSON 为 `null` 等非对象时返回 400；
- 严格拒绝不存在日期、非法小时/分钟和极端分页参数；
- 损坏视频返回 422，响应不再包含服务器绝对路径或 ffprobe 原始 stderr；
- 修复 `Range: bytes=-N` 后缀语义；
- 畸形 URI 编码返回 400。

### 数据与判定

- 新增固定判定快照：结论、依据、明细、容差、规则版本、判定时间；
- 记录生成、读数修正、提交时更新判定快照；复核后、CSV 和 PDF 统一读取快照；
- 启动时自动补齐历史记录判定快照，不改变原 `updated_at`；
- 数据字典和砝码盒局部 PATCH 不再意外重新启用停用对象；
- 模板字段逐项校验，拒绝 `[null]` 和重复字段标识；
- 新记录容差以天平档案为权威来源，历史记录仍使用自身快照；
- 人员/设备卡不再写固定 0.98 置信度，改存解码次数、帧数和首末帧偏移。

### 业务闭环

- 上传进度、失败原因、取消和任务状态继续由上传页与分析任务页承担；未保留重复的独立上传历史页面；
- 同日重复提示改为跨人员、跨设备查询；
- 上传预计天平与实际识别天平不一致时写入任务警告；
- 任务页展示服务器返回的全部 warnings；
- 新增站内通知表、通知中心、未读计数和已读操作；
- 记录退回、复核确认、作废及任务失败会生成定向通知；
- 复核人员登记新天平后可直接重试对应“待人工处理”任务；
- 管理员可批量导出人员卡/设备卡内容清单 CSV；
- 管理员可审计清理源文件已缺失的失败、待处理和已取消任务；
- 待复核页新增提交日期范围筛选；
- 审计日志改为服务端分页，CSV 遍历完整筛选结果，不再受 1 万条单次上限影响。

### 运行与交付

- `/healthz` 同时检查数据库、FFmpeg/FFprobe、PDF 字体、Poppler 和队列；
- 正常关闭将在途任务固定为 `失败/E-SHUTDOWN`，不再留下“分析中”；
- 视频元素改为 `preload=none`，已清理视频不再自动触发 410 控制台错误；
- 所有 `.field` 表单控件自动建立 `label/for`，文件输入补充可访问名称；
- CI 安装 FFmpeg、字体和 Poppler，执行 `npm run check` 与 `npm test`；
- `tests/` 和 `docs/` 纳入 Git 发布策略，不再只留在本机；
- 更新部署、用户、数据库、安全、识别、测试与验收追溯文档。

### 打印

- 单日表：I1-1 到 I3-3 的示值和测量时间分别占独立行；
- 周统计：固定周一至周日 7 个日期列，每个示值/时间独立行；
- 空白表：同步采用逐项行；
- A4 纵向/横向、中文、水印、页码、100 页批量均已重新渲染核验。
