# 天平校验视频分析系统 V1.0.9

## 交付文件

- Windows 10/11 x64 图形化离线安装包
- Linux x86_64 离线安装包
- 中文快速使用说明
- SHA-256 完整性校验文件

Windows 和 Linux 安装包均内置 Node.js 24、FFmpeg/FFprobe、中文字体、纯离线
PDFium 预览组件、whisper.cpp 1.9.2、Whisper base q5_1 量化模型和 Silero VAD。
安装及运行不需要联网，不依赖客户预先安装 Docker、Node.js、FFmpeg 或语音模型。

## 首次使用

安装完成后打开控制面板，使用管理员账号 U000 和界面显示的一次性口令登录。
检验人员账号为 U001/U002，复核确认人员账号为 U003。首次登录后必须修改口令。

## 完整性

使用 SHA256SUMS.txt 核对安装包。安装包当前未进行商业代码签名；正式交付前建议
由组织使用受信任代码签名证书签名。
